# Опалубка · интерактивный DEMO

**Статус:** учебный публичный веб-прототип для GitHub-портфолио. **Не существующий подтверждённый арендодатель.** Каталог и тарифы вымышлены; заказов, реальных отзывов и заявок нет. Контактные данные не запрашиваются, не сохраняются и не отправляются. Проект не является коммерческим предложением.

Это самостоятельная статическая HTML/CSS/JavaScript-демонстрация: адаптивная навигация, фильтрация пяти условных типов опалубки, ввод площади и учебного периода аренды, прозрачная формула локальной сметы. Для работы калькулятора нужен JavaScript. **P1a — промежуточный этап**: полноценное браузерное тестирование, доступность и компонентная архитектура планируются отдельно.

## Запуск без платных сервисов

Нужен любой локальный HTTP-сервер, например Python 3:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Никакого API-ключа, облака, установки npm-пакетов или backend нет.

Для автономных статических тестов требуется **Node.js 22**:

```sh
node --test tests/p1a-static.test.mjs
```

Они проверяют контракт фиктивного демо (отсутствие форм/внешних изображений и ложного подтверждения), структуру ссылок, формулу и граничные значения, фильтры и доступные состояния меню через имитацию DOM. Это **не замена** проверкам настоящим браузером, клавиатурой, axe, screen reader, Lighthouse и скриншотам на 320/360/390/768/1440. Автоматизация запускается workflow `.github/workflows/p1a-static-safety.yml`; статус конкретного запуска следует проверять по PR и SHA, не приравнивая наличие workflow к PASS.

## Учебная формула

```text
Сумма (демо ₽) = площадь (м²) × условный тариф (₽/м²/сутки)
                × (число условных 30-дневных периодов × 30)
                × скидочный множитель из фикстуры
```

Площадь 0,01–10 000 м² (до 2 десятичных знаков), срок 1–12 целых условных периодов. Тарифы (80/90/100/110/120 ₽) и скидки (0–18%) **демонстрационные**, не подтверждены поставщиками. Расчёт не включает доставку, залог, НДС, монтаж или комплектацию и непригоден для реальной аренды.
