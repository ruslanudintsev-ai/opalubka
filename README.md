# Opalubka / LAB — инженерный демо-проект

**О проекте.** Публичный исходный код учебного сайта для портфолио, а **не** действующая компания по аренде опалубки. Оборудование, цены, скидки и схемы вымышлены. Нет реальных заказов, платежей, заявок или сбора контактов.

**Где сам сайт:** поддерживаемая версия — [Astro + TypeScript в `modern/`](./modern/). Для статического размещения используется **содержимое собранной папки `modern/dist/`**, не корень Git-репозитория. **Наличие исходников в `main`, успешного CI или ZIP-артефакта не доказывает, что GitHub Pages опубликован.** Проверенный живой адрес и его SHA должны быть приведены в отдельном отчёте о фактическом деплое; пока такой отчёт не указан, публичная доступность **не подтверждена**.

Локальный запуск (Node.js 24):

```bash
cd modern
npm ci
npm run check
npm test
npm run build
npm run check:artifact
npm run dev
```

Локальный адрес: `http://127.0.0.1:4321/`. Для примера размещения в подпапке `/opalubka/` при сборке задаётся `DEMO_BASE_PATH=/opalubka/`; тесты проверяют ресурсные пути и браузерные сценарии, но это **не** публичный GitHub Pages.

## История и решения

**Историческая точка отсчёта: 29 октября 2026 года, `main@28c1fe9fc8d1aa4817a089dff18a00941fdb39e8`.** Тогда корневой `index.html` содержал неподтверждённые коммерческие утверждения, неподтверждённые сторонние изображения и имитацию отправки заявки. [Аудит P0](./docs/AUDIT_BASELINE.md) сохраняет этот факт для сравнения и **не описывает автоматически сегодняшнее состояние `main`**.

Выбран путь Astro из [PR #5](https://github.com/ruslanudintsev-ai/opalubka/pull/5), а не альтернативный HTML из [PR #4](https://github.com/ruslanudintsev-ai/opalubka/pull/4). [Интеграционный PR #6](https://github.com/ruslanudintsev-ai/opalubka/pull/6) содержит удаление старого корневого HTML и документы P0. **Принятие PR #5, интеграция PR #6 и публикация GitHub Pages — разные события**; проверяйте их статус непосредственно в GitHub, а не по статическому тексту README.

Авторство работ указано честно: владелец задаёт требования, принимает решения о качестве и выпуске, AI-агенты помогают с реализацией кода, дизайна, документации и тестов. CI PASS не означает реальные продажи, пользователей или работающее предприятие.
