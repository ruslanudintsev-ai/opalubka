# Opalubka / LAB — инженерный демо-проект

**Статус:** публичный репозиторий с **неопубликованной новой Astro-версией** в папке [`modern/`](./modern/). Это **учебный продукт для профессионального портфолио**, а не реально работающая компания по аренде опалубки. Товары, ставки, скидки, чертежи и расчёты — демонстрационные, заказов и сбора контактов нет.

> **Важно:** файл [`index.html`](./index.html) в корне — **устаревший прототип** с неподтверждёнными коммерческими утверждениями и ложной имитацией отправки заявки. **Не использовать его как рабочий сайт, не публиковать и не считать подтверждённым продуктом.** Новая версия собирается из `modern/` в `modern/dist/`, а не из корневого HTML. До отдельного согласования владельца корневой файл не заменён и деплоя нет.

Для локального запуска нужен Node.js 24:

```bash
cd modern
npm ci
npm run check
npm test
npm run build
npm run check:artifact
npm run dev
```

Новый сайт будет доступен локально на `http://127.0.0.1:4321/`; это **не публичный адрес**. Отдельный GitHub Actions загружает протестированную статическую сборку `dist/` как артефакт **без деплоя**.

## Зачем сделан проект

Это проверяемый пример **AI-assisted разработки**: владелец определяет задачу, границы риска, критерии приёмки и решение о выпуске; AI-агенты помогают с существенной частью реализации, тестов и документации. Приписывать их программный код человеку неправильно. Зелёные тесты доказывают проверенные сценарии, **не** существование коммерческой компании, реального трафика или доступность live-продукта.

Полный план и контрольные точки: [Issue #2](https://github.com/ruslanudintsev-ai/opalubka/issues/2); [Draft PR #5 — Astro-кандидат](https://github.com/ruslanudintsev-ai/opalubka/pull/5). Альтернативная [Draft PR #4](https://github.com/ruslanudintsev-ai/opalubka/pull/4) с исправлениями старого HTML **не должна смешиваться** с Astro без отдельного решения; аудит в [Draft PR #3](https://github.com/ruslanudintsev-ai/opalubka/pull/3).
